# ESP32-S3 网页与射频控制

当前网页和射频控制已经合并为同一套原生 ESP-IDF 固件。页面由 ESP32 提供 Three.js 3D 视图；开灯、关灯请求会在 ESP32 内通过 CC1101 重放已学习的 `power_sample_1`。

## 烧录

开发板正面朝向你、天线朝上，使用左侧原生 USB 数据口。先退出占用串口的旧监控（Ctrl+]），在项目根目录执行：

```sh
./flash.sh
```

端口变化或多个设备时：

```sh
./flash.sh /dev/cu.usbmodem实际端口
```

`./web-flash.sh` 保留为兼容别名，同样烧录这套合并固件。当前 Wi-Fi 配置放在被忽略的 `main/wifi_config.local.h`；构建后凭据也会进入固件镜像，不能把镜像公开分发。

## 打开页面

等待串口出现实际地址：

```text
OPEN IN BROWSER: http://192.168.x.x/
```

手机和 ESP32 连接同一个可互访 Wi-Fi，在 Safari 或其他浏览器打开完整 `http://` 地址。页面包括白色 80cm 夹子灯、黑色桌面和米白色墙面，可拖动旋转视角。

板载 GPIO48 WS2812 RGB 指示灯会在启动时被清除为全黑，并持续保持熄灭，避免运行一段时间后自行点亮。

## 首次状态校准

原遥控器只发送“切换”信号，没有回传当前开关状态。为了正确执行“开灯/关灯”，ESP32 必须知道你当前看到的灯状态。

首次使用时，按台灯实际情况点击：

- `当前是开灯`
- `当前是关灯`

校准会写入 NVS。之后页面显示“推算：已开启”或“推算：已关闭”，并提供对应可用的开灯、关灯按钮。

## 开灯与关灯

- 目标与推算状态相同：不发送冗余射频命令。
- 目标与推算状态不同：CC1101 单次重放 `power_sample_1`，成功后更新推算状态并保存。
- 多个客户端同时发请求时，ESP32 用互斥锁串行处理，避免 RMT 和 CC1101 并发发送。

页面显示“CC1101 已完成发送”表示重放流程成功，不代表台灯具备状态回传或已执行；以肉眼观察和校准为准。

使用原遥控器、灯身触控或重新给台灯通电后，ESP32 的推算值可能失准。此时点击与实际一致的校准按钮，不需要重新采集信号。

## 本地 3D 资源

- Three.js 0.160.1 和 MIT 许可证保存在 `main/vendor/`。
- HTML、业务脚本和 Three.js 在构建时 gzip 压缩并嵌入应用镜像，不需要单独上传文件系统。
- 手机/电脑负责 WebGL 渲染，ESP32 只返回静态资源和 API，不承担 3D 计算。
- 页面不请求 CDN、外部字体、贴图或模型，断外网仍可从局域网加载。
- 3D 为程序化近似模型，不模拟软管真实机械形变；按钮不会倾斜实体台灯。

## iPhone 主屏幕

`/apple-touch-icon.png` 返回 180×180 的不透明 PNG，与页头 SVG 同款图案。烧录合并固件后，删除旧快捷方式，用 Safari 打开实际地址、刷新，再通过“分享 → 添加到主屏幕”。

## 故障排查

| 现象 | 处理 |
|---|---|
| 串口持续显示 Wi-Fi disconnected | 检查 2.4GHz SSID/密码、信号，以及路由器是否启用特殊网页认证 |
| 串口有 IP，手机打不开 | 确认同一局域网、使用 http、关闭 VPN；路由器可能开启设备隔离 |
| 页面提示 CC1101 未就绪 | 检查 3.3V、GND、SPI、GDO 接线，复位后观察串口 |
| 页面提示未找到 `power_sample_1` | 存储分区可能被擦除或更改；不要继续点发射，需要重新采集开关样本 |
| 页面显示待校准 | 按实际灯光点击“当前是开灯/关灯” |
| 网页状态与实际不一致 | 原遥控器、灯身触控或台灯重新通电后可能改变状态，重新校准 |
| 发送完成但台灯不响应 | 检查 CC1101 天线、距离与供电；用原遥控器确认台灯正常，再回到射频测试流程 |

## 验收

1. ESP32 获取家庭 Wi-Fi IP，手机打开 3D 页面。
2. 按实际状态校准，刷新页面后状态仍保留。
3. 点击与当前状态不同的目标，CC1101 发送一次，台灯实际响应。
4. 再次点击同一目标，不应重复发射。
5. 使用原遥控器改变状态后，网页的推算值可能失准；重新校准后恢复控制。
6. 重启 ESP32，已校准状态和 `power_sample_1` 都应保留。

本机已经通过固件编译、浏览器 API 模拟和 3D 交互测试；最终家庭 Wi-Fi、ESP32 HTTP 和实物射频联动仍需在烧录后按以上步骤验收。
