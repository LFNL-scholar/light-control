# 实物实验记录

记录实物测试事实；编译成功不代表硬件验收通过。

## 设备

- ESP32-S3 开发板：照片丝印 ESP32S3 DevKitC；模组 ESP32-S3-WROOM-1，用户提供后缀 MCN16R8（按 N16R8 规格记录，照片中小字无法独立核清）。2026-10-30 确认。
- 存储规格：N16R8 表示 16MB Flash / 8MB PSRAM；当前固件只使用前 4MB Flash，不启用 PSRAM。
- USB 接口：正面元件朝上、天线朝上、接口朝下时，左侧 USB 为原生 USB，右侧 UART 为 USB 转串口；推荐左侧配合 ./flash.sh。
- CC1101：E07-M1101D-TH（CC1101，433MHz 弹簧天线），已按参考 GPIO 接线。
- 台灯品牌、型号、版本：待填
- 遥控器型号 / 卖家确认的精确频率：待填
- GPIO：已按参考配置实物连接；CC1101 已被识别，能够接收并重放遥控信号。
