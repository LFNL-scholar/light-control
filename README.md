# ESP32-S3 台灯遥控：原生 ESP-IDF

ESP32-S3 + E07-M1101D-TH（CC1101，433 MHz 弹簧天线版）。使用你本机的 **ESP-IDF v6.1**，不需要 Arduino、PlatformIO 或第三方射频库。

板载 GPIO48 WS2812 RGB 灯已主动关闭：启动时发送全黑帧清除锁存颜色，运行中每秒刷新全黑帧并保持数据线低电平。

开关键短按已被实际采集、保存和重放，台灯能够开/关。已确认它是**切换命令**；网页现已支持状态校准以及实物开灯、关灯。亮度、色温、模式与定时属于后续阶段。433.92 MHz / OOK 已对本遥控器完成首次实物验证。

## 一条命令烧录并测试

在本项目目录插入 ESP32-S3，使用开发板的**原生 USB Serial/JTAG 数据口**：

```sh
./flash.sh
```

脚本自动读取本机 EIM 工具链配置、编译、烧录并打开串口，不需要先手动激活环境。只有一块开发板时由 ESP-IDF / esptool 自动选择端口。多个设备时指定：

```sh
./flash.sh /dev/cu.usbmodem你的设备
```

如果使用板上的 **USB 转串口（UART）口**，用下面这一条命令；无需改源码：

```sh
LIGHT_CONSOLE=uart ./flash.sh /dev/cu.usbserial你的设备
```

串口界面按 **Ctrl+]** 退出。若无法自动进入下载模式，按住 BOOT、短按 RESET、松开 BOOT 后再运行烧录。

**烧录前核对实际开发板的 GPIO 和 Flash。**默认目标为 ESP32-S3，使用 4MB Flash 布局，无 PSRAM 依赖；8MB/16MB 板子也可只使用前 4MB。参考 GPIO 是可修改配置，不代表所有带屏或特殊 S3 开发板都可直接照接。

当前家庭 Wi-Fi 配置保存在被忽略的 `main/wifi_config.local.h`。编译后的固件包含该凭据，不要把固件镜像公开分发。

## v2 网页功能

网页支持自动 / 浅色 / 深色：自动模式按北京时间 08:00–18:00 浅色，其余深色，各浏览器独立记住手动偏好。新增日时间轴、开关与校准记录、周/月每日时长、总时长及有效记录日均。

统计为网页控制和校准产生的**推算数据**，设备保存最近 12 个月，多手机共享，关闭网页仍累计。设备每次重启后需重新校准；断电/时间未同步期间显示未知，不补算时长。SNTP 首次校时需要外网；灯光控制和所有网页资源仍可在局域网使用。

详见 [v2 功能、存储规则与验收](docs/v2/功能与验收.md)。本机测试与原生 USB 构建通过不等于实物烧录验收，新增功能仍需按文档在开发板测试。

## 首次使用

烧录后等待串口打印：

```text
OPEN IN BROWSER: http://192.168.x.x/
```

手机连接家庭 Wi-Fi，打开实际打印的地址。首次没有保存灯光状态时，先按台灯实际状态点击“当前是开灯”或“当前是关灯”。校准后，“开灯/关灯”按钮会在需要时通过 CC1101 发送已保存的 `power_sample_1`，并更新推算状态。

原遥控器只有一个切换命令，没有状态回传。使用原遥控器、灯身触控或重新通电后，如果网页状态与实际不一致，再点击页面上的状态校准按钮。

## 原生构建与目录

只编译、不烧录：

```sh
./build.sh
```

| 路径 | 用途 |
|---|---|
| `main/config.h` | GPIO、默认参数和缓冲区上限 |
| `main/cc1101.c` | 原生 SPI 驱动、超时、配置读回、RX/TX 状态确认 |
| `main/waveform.c` | RMT DMA 收发，1μs 分辨率 |
| `main/storage.c` | SPIFFS 波形槽位，CRC32 校验 |
| `main/lamp_controller.c` | 已学习开关样本、推算状态、NVS 持久化与串行射频发送 |
| `main/history.c` | 用灯区间、NVS 检查点、断电恢复、12 个月清理与历史输出 |
| `main/stats.js` | 北京时间日历、主题规则与日/周/月统计计算 |
| `main/web_server.c` | 本地 Three.js 页面、状态 API 与开关 API |
| `main/status_led.c` | 用 RMT 将 GPIO48 板载 WS2812 清除并保持关闭 |
| `main/app_main.c` | Wi-Fi 连接和整个系统初始化 |
| `build/` | 原生 USB 版本生成文件、sdkconfig |
| `build-uart/` | UART 版本生成文件、sdkconfig |

脚本默认使用 `$HOME/.espressif/tools/activate_idf_v6.1.sh` 的 EIM `-e` 导出接口，不会修改全局 IDE 选择。已有完整 IDF 环境时直接复用。EIM 路径变化可用 `LIGHT_IDF_ACTIVATE=/路径/activate_idf_v6.1.sh ./build.sh` 指定。

如果已经手动激活原生 IDF，也可以直接运行 `idf.py build`、`idf.py -p PORT flash monitor`；为复用脚本构建目录与配置，建议始终使用上述脚本。
